# Contributing

Bug reports and patches are welcome. Please read this whole page first.

## Tests

Run `python -m pytest` and add a test for every fix.

## AI-generated contributions

We do not accept pull requests that were generated or substantially written by AI tools
or coding agents (ChatGPT, Copilot, Claude, Cursor and similar). Reviewing them has cost
us more time than they saved. Such pull requests will be closed without review, and
repeat submitters will be blocked. Automated/bot PRs are likewise not accepted.
